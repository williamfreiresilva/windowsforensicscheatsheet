Setup & tools

Run as
Administrator — some hives won't load fully otherwise.
RegistryExplorer.exe "C:\path\to\hive"
Manual load
File > Load hive. Accept sequence-number warning (Yes). Select both .LOG1 and .LOG2. Load the updated hive (Yes), not the dirty one (No).

Hives

For each hive: what it answers, interesting artifacts, investigative questions, how to analyze.

SYSTEM

C:\Windows\System32\config\SYSTEM
Answers
Hardware/system config: USB history, services, network, timezone, computer name, active ControlSet.
Artifacts
USBSTOR/USB, ShimCache, Services, BAM/DAM, Tcpip\Interfaces.
Ask
Which USB devices connected, when? New service = persistence? What binary passed through (ShimCache)? What timezone (to correlate timestamps)?
How
Registry Explorer (USB Devices, Services bookmarks) or RECmd for batch; AppCompatCacheParser for ShimCache.

SOFTWARE

C:\Windows\System32\config\SOFTWARE
Answers
Machine-wide info (not per-user): OS version, installed programs, global autostart, USB friendly name, known Wi-Fi.
Artifacts
CurrentVersion, Run/RunOnce (machine), Windows Portable Devices\Devices, NetworkList\Profiles, Uninstall.
Ask
What ran automatically on boot for any user? What's the USB friendly name? What networks has this host joined?
How
Registry Explorer, Autoruns/Installed Programs bookmarks; RECmd for batch.

SAM

C:\Windows\System32\config\SAM
Answers
Local user accounts: who exists, last logon, password hint, password hash (for offline cracking).
Artifacts
SAM\Domains\Account\Users
Ask
How many accounts exist? Any that never logged in (attacker-created)? What's a specific user's password hint?
How
Registry Explorer, 'Users' bookmark. Loading SYSTEM alongside helps decode some values.

SECURITY

C:\Windows\System32\config\SECURITY
Answers
Local security policy and LSA secrets: audit policy (why certain Event IDs show up or not), cached domain credentials.
Artifacts
Policy\PolAdtEv, Cache, LSA Secrets.
Ask
Which audit policies were active? Any cached domain credentials on this host?
How
Registry Explorer loads it, but many values are binary/encrypted — more context than direct answers.

NTUSER.DAT

C:\Users\<user>\NTUSER.DAT
Answers
Everything about ONE user's activity: what they ran, opened, typed, what starts at their logon.
Artifacts
UserAssist, RecentDocs, TypedPaths/WordWheelQuery, Run/RunOnce (user), ComDlg32, Shell\BagMRU.
Ask
What did this user execute, with full path? What files did they open? What did they type in Explorer?
How
Load the suspect user's NTUSER.DAT; UserAssist and RecentDocs bookmarks.

UsrClass.dat

C:\Users\<user>\AppData\Local\Microsoft\Windows\UsrClass.dat
Answers
Completes the folder-browsing trail (ShellBags) — Explorer window state per folder, even deleted or removable ones.
Artifacts
Local Settings\Software\Microsoft\Windows\Shell\BagMRU and \Bags.
Ask
Which folders did the user browse, even if gone now? Any folder on a USB or network share?
How
Best via SBECmd — merges NTUSER.DAT + UsrClass.dat and rebuilds full paths with timestamps automatically.
